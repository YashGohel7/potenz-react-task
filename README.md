# Potenz React Task

## Features

- User Authentication
- Protected Routes
- Dashboard
- Products Listing
- Product Details Page
- Pagination
- User Profile
- Loader
- Logout Functionality

---

## Technologies Used

- React JS
- React Router DOM
- Axios
- Bootstrap
- Vite
- DummyJSON API

---

## API Endpoints

- https://dummyjson.com/users
- https://dummyjson.com/products
- https://dummyjson.com/auth/login

---

## Installation

Clone repository:

```bash
git clone YOUR_GITHUB_LINK
```

Install dependencies:

```bash
npm install
```

Run project:

```bash
npm run dev
```

---

## Environment Variables

Create `.env` file:

```env
VITE_API_URL=https://dummyjson.com
```
